A partial function \(f : \mathbb {N}\to \mathrm{Part}\, \mathbb {N}\) is partial recursive if and only if there exists a finite-state \(\mathrm{TM0}\) machine over \(\Gamma _0\) computing \(f\) under encNat/decNat.
